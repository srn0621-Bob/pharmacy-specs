# Spec 10: 订单状态管理 - 需求文档

## 文档信息

**Spec编号:** patient-mall-phase4-order-status  
**功能名称:** 订单状态管理  
**所属阶段:** 阶段四 - 订单功能  
**创建日期:** 2026-01-23  
**依赖关系:** 依赖Spec 8订单创建功能

---

## 简介

实现患者端药品商城的订单状态流转管理，包括取消订单、确认收货、订单状态验证和库存恢复等功能。

## 术语表

| 术语 | 定义 |
|------|------|
| 订单状态 | 订单当前所处的生命周期阶段 |
| 状态流转 | 订单从一个状态变更到另一个状态 |
| 取消订单 | 用户主动取消未支付或待发货的订单 |
| 确认收货 | 用户确认已收到商品 |
| 库存恢复 | 取消订单时将已扣减的库存返还 |

---

## 订单状态定义

| 状态码 | 状态名称 | 说明 |
|--------|---------|------|
| 1 | 待支付 | 订单已创建，等待用户支付 |
| 2 | 待发货 | 订单已支付，等待商家发货 |
| 3 | 待收货 | 订单已发货，等待用户确认收货 |
| 4 | 已完成 | 订单已完成 |
| 5 | 已取消 | 订单已取消 |

---

## 状态流转规则

```
待支付(1) ──取消订单──> 已取消(5)
    │
    │支付成功
    ↓
待发货(2) ──取消订单──> 已取消(5)
    │
    │商家发货
    ↓
待收货(3) ──确认收货──> 已完成(4)
    │
    │超时自动确认
    ↓
已完成(4)
```

---

## 功能需求 (EARS格式)

### FR-1: 取消待支付订单
**WHEN** 用户取消待支付状态的订单  
**THE SYSTEM SHALL** 将订单状态更新为"已取消"  
**AND** 恢复已扣减的库存

### FR-2: 取消待发货订单
**WHEN** 用户取消待发货状态的订单  
**THE SYSTEM SHALL** 将订单状态更新为"已取消"  
**AND** 恢复已扣减的库存  
**AND** 触发退款流程

### FR-3: 确认收货
**WHEN** 用户确认收货  
**THE SYSTEM SHALL** 将订单状态从"待收货"更新为"已完成"  
**AND** 记录确认收货时间

### FR-4: 状态流转验证
**WHEN** 系统执行状态变更时  
**THE SYSTEM SHALL** 验证状态流转是否合法  
**IF** 状态流转不合法  
**THEN** 拒绝操作并返回错误信息

### FR-5: 库存恢复
**WHEN** 订单被取消时  
**THE SYSTEM SHALL** 恢复订单中所有商品的库存  
**WHERE** 恢复数量等于订单中的商品数量

### FR-6: 超时自动确认收货
**WHEN** 订单发货后超过7天未确认收货  
**THE SYSTEM SHALL** 自动将订单状态更新为"已完成"

---

## 非功能性需求

### NFR-1: 性能要求
- 状态更新响应时间 < 1秒
- 库存恢复必须原子性操作

### NFR-2: 可靠性要求
- 状态流转必须符合业务规则
- 库存恢复不能出错

### NFR-3: 安全性要求
- 用户只能操作自己的订单
- 已发货订单不能取消

## API接口定义

### 取消订单接口

**接口路径:** `POST /api/patient/mall/order/cancel`

**请求参数:**
```json
{
  "orderId": 789,
  "patientUserId": 123,
  "cancelReason": "不想要了"
}
```

**响应示例:**
```json
{
  "code": 200,
  "message": "订单取消成功",
  "data": {
    "orderId": 789,
    "status": 5,
    "statusName": "已取消"
  }
}
```

### 确认收货接口

**接口路径:** `POST /api/patient/mall/order/confirm`

**请求参数:**
```json
{
  "orderId": 789,
  "patientUserId": 123
}
```

**响应示例:**
```json
{
  "code": 200,
  "message": "确认收货成功",
  "data": {
    "orderId": 789,
    "status": 4,
    "statusName": "已完成",
    "confirmTime": "2026-01-23 20:00:00"
  }
}
```
