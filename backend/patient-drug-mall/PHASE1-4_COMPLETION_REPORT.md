## 🔧 技术实现

### 数据库设计
```
新增表:
  - t_drug_category (药品分类表)
  - t_cart (购物车表)
  - t_mall_order (商城订单表)
  - t_mall_order_item (订单明细表)

扩展表:
  - t_drug (新增8个商城字段)

索引优化:
  - idx_category_id (分类查询)
  - idx_user_id (用户查询)
  - idx_order_no (订单查询)
  - idx_status (状态筛选)
```

### 缓存策略
```
Redis缓存:
  - 药品详情: 30分钟
  - 相关推荐: 10分钟
  - 订单详情: 30分钟
  - 搜索历史: 30天(List结构)
  - 热门搜索: 永久(ZSet结构)
```

### 事务管理
```
事务场景:
  - 订单创建(订单+明细+库存+购物车)
  - 订单取消(订单状态+库存恢复)
  - 订单确认收货(订单状态更新)

隔离级别: READ_COMMITTED
传播行为: REQUIRED
回滚策略: rollbackFor = Exception.class
```

### 并发控制
```
乐观锁:
  - 订单状态更新(使用status字段)
  - 库存扣减(使用stock字段)

悲观锁:
  - 库存扣减SQL(WHERE stock >= quantity)
```
