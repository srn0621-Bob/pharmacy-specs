# 患者端药品商城UI综合实施 Spec

> **状态**: 📝 规划中  
> **优先级**: P0 (核心功能)  
> **预计工期**: 3-4周  
> **目标**: 功能完整性 + 视觉一致性75-80%

## 概述

本spec综合了 `patient-pharmacy-ui-migration` 和 `patient-mall-ui-redesign-implementation` 两个spec的内容,旨在一次性完成从dingdang-pharmacy React Web应用到Android患者端的完整迁移,同时确保高度的视觉一致性。

## 核心目标

1. **功能完整性**: 实现所有核心购物流程(浏览、搜索、购物车、结算)
2. **视觉一致性**: 达到75-80%的视觉一致性评分
3. **性能优化**: 页面加载<2秒,动画帧率≥55fps
4. **代码质量**: 清晰的架构,可维护的代码,完整的注释

## 关键特性

### 视觉系统

- **主题色**: 翠绿色 #10b981 (替代原有的橙色)
- **圆角系统**: 3dp-9999dp (pill形状用于按钮和搜索框)
- **标签系统**: 快递送(橙色)、自营(绿边)、促销(绿色)、赠品(橙边)
- **自定义组件**: DingdangTagView、DingdangCheckBox

### 核心功能

- **商城首页**: 固定Header、轮播图、分类导航、热销药品、推荐药品
- **药品详情**: 图片轮播、促销标签、用药指导、店铺信息、相关推荐
- **购物车**: 店铺信息栏、活动提示、圆形选中、预估到手价、常买常逛
- **结算页面**: 地址选择、商品列表、价格明细、支付方式
- **搜索功能**: 搜索历史、热门搜索、实时建议、搜索结果
- **分类浏览**: 分类列表、药品列表、分页加载
- **底部导航**: 首页、分类、购物车、我的

### 技术架构

- **架构模式**: MVP (Model-View-Presenter)
- **网络框架**: Retrofit 2.2.0 + OkHttp 3.10.0
- **响应式编程**: RxJava 2.1.7 + RxAndroid 2.0.1
- **图片加载**: Glide 4.12.0
- **列表组件**: RecyclerView + BaseRecyclerViewAdapterHelper
