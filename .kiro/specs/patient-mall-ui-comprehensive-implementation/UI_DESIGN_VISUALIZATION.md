## 设计概览

### 核心特色
- **主题色**: 翠绿色 (#10b981)
- **圆角系统**: 3dp-16dp统一圆角
- **标签系统**: 快递送、自营、促销、赠品四种标签
- **自定义组件**: DingdangTagView、DingdangCheckBox
- **架构模式**: MVP架构

### 页面清单
1. 商城首页 (MallHomeFragment)
2. 药品详情页 (DrugDetailActivity)
3. 购物车页面 (MallCartFragment)
4. 结算页面 (CheckoutActivity)
5. 搜索页面 (SearchActivity)
6. 分类页面 (MallCategoryFragment)
7. 我的页面 (MallMineFragment)

3. **标签系统**: 处方药、医保、OTC、自营等标签清晰标识
4. **促销突出**: 绿色图标 + 文字说明，吸引用户注意
5. **服务保障**: 28分钟送达、药师咨询、正品保障等增强信任
6. **Tab切换**: 商品详情、用药指南、常见问题分Tab展示
7. **底部固定**: 操作按钮固定在底部，方便用户随时操作
