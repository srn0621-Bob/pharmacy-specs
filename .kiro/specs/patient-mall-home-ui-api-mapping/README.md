# 患者端药品商城首页 UI-API 映射规范

## 概述

本规范文档详细定义了患者端药品商城首页（MallHomeFragment）的 UI 元素、用户交互事件和后端 API 的映射关系。通过可视化的方式展示页面结构、数据流向和交互逻辑，为前后端开发提供清晰的技术规范。

## 核心内容

### 1. 页面结构

商城首页包含以下核心元素：

```
┌─────────────────────────────────────────┐
│ 固定头部 (搜索框 + 热门标签)            │
├─────────────────────────────────────────┤
│ 快捷入口 (8个圆形图标，4x2网格)         │
├─────────────────────────────────────────┤
│ 轮播图 (HBanner，自动轮播)              │
├─────────────────────────────────────────┤
│ 闪购专区 (横向滚动列表)                 │
├─────────────────────────────────────────┤
│ 推荐药品 (2列网格列表)                  │
└─────────────────────────────────────────┘
```

### 2. API 映射关系

| UI 元素 | API 端点 | 方法 | 状态 |
|---------|---------|------|------|
| 轮播图 | `/api/v1/homepage/list` | POST | ✅ 已实现 |
| 热门标签 | `/api/v1/homepage/list` | POST | ✅ 已实现 |
| 闪购药品 | `/api/v1/mall/drugs/recommended` | GET | ✅ 可复用（筛选有折扣的推荐药品） |
| 推荐药品 | `/api/v1/mall/drugs/recommended` | GET | ✅ 已实现 |

**重要发现**：根据 API_REUSE_ANALYSIS.md 分析，现有后端 API 已经实现了 90% 以上的功能，可以直接重用！

### 3. 用户交互事件

| 交互元素 | 事件类型 | 目标页面 | 数据传递 |
|---------|----------|----------|----------|
| 搜索框 | onClick | SearchActivity | - |
| 快捷入口 | onItemClick | 根据action跳转 | action参数 |
| 轮播图 | onBannerClick | WebViewActivity | linkUrl |
| 药品卡片 | onItemClick | DrugDetailActivity | drugId, drugName |
| 下拉刷新 | onRefresh | - | - |

### 4. 数据模型

#### Drug (药品)

```java
{
  "id": "2001",
  "name": "布洛芬缓释胶囊",
  "spec": "0.3g*20粒",
  "price": 18.50,
  "imageUrl": "https://...",
  "sales": 3500,
  "stock": 1200,
  "isPrescription": false
}
```

#### Banner (轮播图)

```java
{
  "id": "1",
  "imageUrl": "https://...",
  "linkUrl": "https://...",
  "title": "新春大促"
}
```
