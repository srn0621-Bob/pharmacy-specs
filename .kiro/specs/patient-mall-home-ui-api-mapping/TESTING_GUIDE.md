## 🔍 问题排查

### 如果首页仍然无数据显示

1. **检查 API 响应**
   ```bash
   adb logcat | grep "MallHomePresenter"
   ```
   - 查看 API 是否返回 200
   - 查看返回的数据量

2. **检查解析错误**
   ```bash
   adb logcat | grep -E "(JsonSyntaxException|empty String)"
   ```
   - 如果有 "empty String" 错误，说明修复未生效
   - 需要重新安装 APK

3. **检查网络连接**
   - 确认设备能访问后端 API
   - 尝试手动刷新（下拉刷新）

### 如果轮播图仍然崩溃

1. **检查崩溃日志**
   ```bash
   adb logcat | grep -E "(IndexOutOfBoundsException|HBanner)"
   ```
   - 查看崩溃堆栈信息
   - 确认是否是 HBanner 相关

2. **检查轮播图状态**
   ```bash
   adb logcat | grep "showBanners"
   ```
   - 查看轮播图是否有数据
   - 查看是否正确启用/禁用

3. **重新安装 APK**
   ```bash
   cd mshlwyy_patient-mall
   ./gradlew clean
   ./gradlew assembleDebug -x lint
   ./gradlew installDebug
   ```
