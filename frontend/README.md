# 前端 UI 规范

本目录包含前端 Android 应用相关的技术规范文档。

## 📋 规范列表

### 综合项目
- **patient-drug-mall** - 患者端药品商城完整实现(45 个文档)
  - 包含 API 依赖、页面流程、编译修复、进度报告等完整文档
  - 涵盖从需求到交付的全过程文档
- **patient-pharmacy-ui-migration** - 患者端药房 UI 迁移(15 个文档)
  - 包含 UI 一致性分析、实现总结、项目交付等文档

### UI 分阶段实现 (Phase 1-11)

#### Phase 1: 基础准备
- **patient-mall-ui-01-foundation** - UI 基础框架搭建
- **patient-mall-ui-02-resources** - 资源文件准备(图片、颜色、字符串)

#### Phase 2: 核心页面
- **patient-mall-ui-03-home** - 商城首页实现
- **patient-mall-ui-04-detail** - 药品详情页实现
- **patient-mall-ui-05-cart** - 购物车页面
- **patient-mall-ui-06-checkout** - 订单结算页面

#### Phase 3: 辅助功能
- **patient-mall-ui-07-search** - 药品搜索页面
- **patient-mall-ui-08-category** - 药品分类页面
- **patient-mall-ui-09-navigation** - 页面导航实现

#### Phase 4: 优化与测试
- **patient-mall-ui-10-optimization** - UI 性能优化
- **patient-mall-ui-11-testing** - UI 功能测试
