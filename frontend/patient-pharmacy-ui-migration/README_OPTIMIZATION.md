# Spec优化快速指南

> 如何通过修改spec提高与dingdang-pharmacy的一致性

## 📊 当前状态

- **一致性评分**: 60-65%
- **主要差距**: 视觉设计(40%)、交互体验(50%)、信息密度(60%)
- **根本原因**: Spec未明确要求视觉一致性

## 🎯 优化目标

通过优化spec文档,将一致性从**60-65%**提升到**75-80%**

## 📋 核心优化内容

### 1. Requirements.md 优化

**新增需求**:
- 需求8: 视觉一致性需求
- 明确主题色、圆角、标签等视觉规范

**优化现有需求**:
- 增强验收标准,明确"如何显示"
- 添加视觉呈现的具体要求

### 2. Design.md 优化

**新增内容**:
- 独立的dingdang颜色系统(翠绿色)
- 扩展的圆角系统(包含pill形状)
- 自定义组件设计(标签、圆形选中、固定Header)
- 详细的页面布局设计

**关键变更**:
- 主题色: 橙色(#ee8934) → 翠绿色(#10b981)
- 圆角: 8-12dp → 16-24dp + pill(9999dp)
- 新增: DingdangTagView、DingdangCheckBox组件

### 3. Tasks.md 优化

**新增任务**:
- Spec 2.5: 视觉基础重构(P0)
- Spec 2.6: 自定义组件实现(P0)
- Spec 11: 交互动画实现(P2)

**优化现有任务**:
- Spec 3: 商城首页 - 细化到具体UI组件
- Spec 4: 药品详情页 - 新增促销标签、用药指导等
- Spec 5: 购物车 - 新增店铺信息栏、常买常逛等

## 🚀 实施方案

### 快速方案 (1周)

**目标**: 达到65-70%一致性

**任务**:
1. 创建dingdang颜色/尺寸/样式资源
2. 实现DingdangTagView和DingdangCheckBox
3. 实现固定Header

### 完整方案 (3-4周)

**目标**: 达到75-80%一致性

**阶段**:
1. 视觉基础重构 (1周, P0)
2. 首页优化 (3-4天, P0+P1)
3. 详情页优化 (3-4天, P1)
4. 购物车优化 (2-3天, P1)
5. 交互动画 (2-3天, P2)
