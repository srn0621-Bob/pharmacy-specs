## 🎯 核心业务流程

### 完整的购物流程 ✅

```
┌─────────────┐
│  商城首页    │ MallHomeFragment
│  - 分类展示  │
│  - 热销药品  │
│  - 推荐药品  │
└──────┬──────┘
       │ 点击药品
       ↓
┌─────────────┐
│  药品详情    │ DrugDetailActivity
│  - 图片轮播  │
│  - 详细信息  │
│  - 推荐药品  │
└──────┬──────┘
       │ 加入购物车
       ↓
┌─────────────┐
│  购物车      │ CartFragment
│  - 商品列表  │
│  - 数量修改  │
│  - 价格计算  │
└──────┬──────┘
       │ 去结算
       ↓
┌─────────────┐
│  结算页面    │ CheckoutActivity
│  - 地址选择  │
│  - 价格明细  │
│  - 支付方式  │
└──────┬──────┘
       │ 提交订单
       ↓
┌─────────────┐
│  订单创建    │
│  - 移除购物车│
│  - 跳转支付  │
└─────────────┘
```

### 数据流转

```
用户操作 → View (Fragment/Activity)
         ↓
      Presenter (业务逻辑)
         ↓
      Model (数据模型)
         ↓
      Util (工具类)
         ↓
   SharedPreferences / API
```

## 🏆 技术亮点

### 1. MVP 架构模式
- **View 层:** 只负责 UI 展示和用户交互
- **Presenter 层:** 处理业务逻辑和数据转换
- **Model 层:** 封装数据结构和业务规则
- **优势:** 职责清晰,易于测试,易于维护

### 2. 单例模式
- **CartManager:** 全局共享购物车数据
- **线程安全:** 双重检查锁定
- **优势:** 避免重复创建,数据一致性

### 3. 适配器模式
- **DrugListAdapter:** 支持横向和纵向两种布局
- **通过构造函数传入不同的 layoutResId**
- **优势:** 一个适配器复用多个场景

### 4. 工具类封装
- **ImageLoader:** 封装 Glide 图片加载
- **PriceCalculator:** 封装价格计算逻辑
- **CartManager:** 封装购物车管理
- **优势:** 统一接口,易于替换实现

### 5. 组件化布局
- **搜索栏、标题、空状态等公共组件**
- **使用 `<include>` 标签复用**
- **优势:** 减少重复代码,提高一致性

### 6. 精确价格计算
- **使用 BigDecimal 处理价格**
- **避免浮点数精度问题**
- **优势:** 金额计算精确无误
